RentEarth is a turn-based 4X in the Civilization tradition — explore, expand,
exploit, exterminate — being built in the open by [KBVE](https://github.com/KBVE).

## Why the schemas came first

A 4X is a long game. State accumulates across hundreds of turns, and a save
written by one build has to keep meaning something to the next one. That is a
data-model problem before it is a gameplay problem, so the wire format is being
settled before the systems that ride on it.

The definitions live in Protobuf and generate TypeScript, Rust, C# and Python
from a single source. The website reads the same `Rarity` enum the server does.
Renaming a field breaks every consumer in the same minute rather than silently
in one of them.

## What is decided

The genre and the turn structure. The systems being modelled so far are items,
spells, quests, dialogue and rarity.

## What is not

The map, the eras, the victory conditions, and the engine the client runs on.
When those are settled they will show up here, and not before.
