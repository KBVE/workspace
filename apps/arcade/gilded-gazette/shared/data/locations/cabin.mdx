Berths one to eight, each with a door that locks from inside and a key that
opens it from without.

## Appearance

A folding basin, a reading lamp, and a mirror mounted where it catches the
corridor whenever the door stands open.

## The Keys

The conductor holds a pass key and says he has not used it. There is a second
pass key, and no ledger records who signed for it.
